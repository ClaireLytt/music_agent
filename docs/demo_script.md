# 路演脚本 · 黄金路径（3–5 分钟）

一条主线讲透「从一句歌词到一个歌手的宇宙」，其余功能一页带过。
演示机要求：已跑完 `demo-prep` 检查、服务器**不要中途重启**（彩蛋图内存缓存会丢）。

## 开场白（15s）

> 「每个人都有一句单曲循环时突然听懂的歌词。歌词透镜让这个瞬间可以被展开、被追溯——
> 它不只是播放器，是歌词的研究工具。」

## 分镜

### ① 打开应用 → 晴天自动就位（30s）
- **操作**：打开 http://127.0.0.1:7860（提前开好，切屏即达）。
- **画面**：默认落在《晴天》，点 ▶ 播放——歌词逐句高亮 + 逐字卡拉OK渐变。
- **讲词**：时间轴级同步，不是滚动字幕；注意韵脚圆点（🎯 开着）同韵同色。
- **兜底**：音频缺失/没声音 → 直接点歌词行讲批注，跳过播放拍。

### ② 点一句歌词 → AI 批注展开（45s）
- **操作**：点「从前从前有个人爱你很久」（或现场任选一句）。
- **画面**：右侧展开该句的修辞、意象、情感分析。
- **讲词**：全库逐句预生成，不是现场编的——点哪句都有。可顺手双击一个词演示取词。
- **兜底**：批注加载慢 → 换一句（缓存热的句子秒出）。

### ③ 🥚 彩蛋 → 同歌手互文（45s）
- **操作**：点「刮风这天 我试过握着你手」（带 🥚，实测 0.827 强呼应）→
  彩蛋面板对出《简单爱》「牵着你的手 一阵莫名感动」。
- **讲词**：语义检索不是关键词匹配——"握着你手"和"牵着你的手"是语义对上的；
  中文用更严阈值防字面撞车。
- **兜底**：用页面底部「本歌彩蛋总览」挑一条强的。

### ④ 彩蛋地图 → 周杰伦互文网络（45s）
- **操作**：切「🥚 彩蛋地图」页签（歌手已默认周杰伦）→ 视图切「🕸️ 整体网络」。
- **画面**：周杰伦全库曲目的互文网络，连线粗细=呼应数，悬停看具体歌词对。
- **讲词**：从一句歌词的呼应，放大到整个创作生涯的回声网络。
- **兜底**：网络连线淡（单对呼应透明度低）→ 焦点视图切《告白气球》
  （4 条强边、跨 3 首歌，星形图最好看）。

### ⑤½ 可选加时拍 · MCP（30s，网络/环境稳定时才上）
- **操作**：切到 Claude（Code/Desktop），说「放一首周杰伦关于雨的歌」→
  镜头切回浏览器——播放器已切到对应歌曲并开始播放。
- **讲词**：歌词透镜不只是用 AI 的播放器，也是 AI 可以使用的播放器——
  内置 MCP 服务器，任何 AI 助手都能检索曲库、解读歌词、驱动播放。
- **兜底**：MCP 响应慢或自动播放被拦 → 直接跳过，此拍不影响主线。

### 收尾（15s）
> 「从一句歌词，到两首歌的呼应，到一个歌手的叙事宇宙——
> 接入 QQ 音乐曲库后，每一位歌手、每一位听众都能拥有这样一座透镜。」

## 没讲到的功能（slide 一页带过）

歌词竞猜/拼图 · 歌迷考据 · 分享金句卡 ·

## 事故预案

| 状况 | 动作 |
|---|---|
| WiFi 挂 | 全链路本地可跑（embedding/声纹/图全本地）；只有现场 LLM 调用受影响 → 全靠预热缓存 |
| LLM Key 401/超时 | 不现场重试；一切展示走缓存（批注/MV彩蛋均已落盘） |
| 服务器崩 | 不现场调试，切备份演示视频 |
| 投影分辨率异常 | 浏览器 Ctrl+- 缩到 80%；歌词区优先保证可读 |
