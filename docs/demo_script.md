# 路演脚本 · 黄金路径（3–5 分钟）

一条主线讲透「听英文歌 → 问懂一句 → 把生词练会」，其余功能一页带过。
演示机要求：已跑完 `demo-prep` 检查、服务器**不要中途重启**。

## 开场白（15s）

> 「喜欢英文歌的人都有这个瞬间：旋律会唱了，歌词没听懂。查词太枯燥，
> 背词坚持不下去。歌词透镜把这件事变成一个闭环——点一句歌词，AI 把它
> 讲懂；双击生词收藏；再用盲打把它练会带走。」

## 分镜

### ① 打开应用 → cardigan 自动就位（30s）
- **操作**：打开 http://127.0.0.1:7860（提前开好，切屏即达）。
- **画面**：默认落在 cardigan，点 ▶ 播放——歌词逐句高亮 + 逐字卡拉OK渐变。
- **讲词**：时间轴级同步，不是滚动字幕；注意韵脚圆点（🎯 开着）同韵同色。
- **兜底**：音频缺失/没声音 → 直接进②，跳过播放拍。

### ② 听不懂的那句 → 点它问 AI（45s）
- **操作**：点 "I knew you'd come back to me"，右侧 AI 助手用中文讲这句；
  再点 ✏️ 看逐句批注；点 🀄 显示中文翻译看整首对照。
- **讲词**：三个深度任选——问答（随便追问）、批注（修辞/情绪/用典）、
  对照翻译（一次生成永久缓存）。

### ③ 生词 → 双击收藏（30s）
- **操作**：双击 "vintage" → 词义卡（音标/释义/真例句，卡片可拖动）→
  ⭐ 收藏；📝 给它写一句自己的笔记。
- **讲词**：例句来自真实词典（零 AI 成本），收藏自动带上"它出自哪句歌词"。

### ④ 🔤 歌曲寻词 → 把词练会（60s）
- **操作**：切到 🔤，点「开始/换一词」——盲打 vintage：打错整词重来、
  Tab 偷看、Enter 换词；点出处歌词跳回那句去听。
- **讲词**：qwerty-learner 式肌肉记忆 + 词永远带着歌的语境；
  练不熟的词出现更频繁；支持导入自己的单词表分组练、导出 Anki。

### ⑤ 一页带过（30s）
- 🎮 互动：歌迷考据（AI 把官方信息/歌词呼应/推测写成故事页）、竞猜、拼图。
- ➕ 添加歌曲：贴歌名自动配歌词和 B 站 MV；回声/检索索引后台自动重建。
- MCP：对话式控制播放器（"放一首 cardigan"）。

## 收尾（15s）

> 「从听不懂，到问懂，到练会——歌词透镜让喜欢的歌变成坚持得下去的
> 英语课。」

## 预案

- LLM 慢/挂：②用已缓存批注与翻译演示；考据页有 tolerate it 缓存。
- 断网：例句/发音静默降级，主线不受影响。
