# Learn From Music

**听英文歌，把英语学会。**

不是背单词软件，也不是歌词翻译站。它做一件很具体的事：**把你喜欢的那首歌，变成你的英语教材。**

点一句歌词，AI 用中文把这句讲懂；双击一个生词，词义、发音、它在别的歌里怎么用，一次给全；收藏之后，用盲打把它练到手指会。

## 为什么做这个

喜欢英文歌的人大概都经历过这个瞬间：旋律已经会哼了，歌词还是没听懂。

传统做法是查词典、抄生词、背单词表——问题是**单词一离开那句话就死了**。你背下 `vintage` 的意思是"复古的"，但下次在歌里听到它，还是反应不过来。

这个项目想提供的不是一堆功能，而是一条**学习思路**：

| 原则 | 具体做法 |
|---|---|
| **语境优先** | 单词永远带着它出生的那句歌词。收藏的是"这句里的这个词"，不是孤立的词条 |
| **先懂再记** | 听不懂的句子当场问 AI，搞懂语法、俚语、情绪，理解之后再谈记忆 |
| **输入转输出** | 听懂只是输入。盲打练习强迫你把词"写"出来，才算真的会 |
| **难度自适应** | 下一轮把错得多的词排到队首，练熟的词自动靠后；不平均用力 |
| **成果可迁移** | 单词本可以导出成 Anki / qwerty-learner 格式，接着用你熟悉的工具练 |

一句话：**让喜欢的歌，变成坚持得下去的英语课。**

## 学习闭环

整个产品围绕四步设计，界面上也是按这个顺序摆的：

```
① 听        ② 问懂          ③ 查词收藏        ④ 练会
逐句高亮  →  点句问 AI    →  双击单词弹卡    →  盲打整词
卡拉OK渐变   逐句 AI 批注     音标/释义/发音     错词优先重练
             整首歌曲导读     全库出现位置       分组训练
                              AI 语境解释       导出 Anki
```

每一步的产出都会流到下一步：**问懂的那句**可以整句收藏；**收藏的词**自动带原句进单词本；**单词本**就是练习题库。

## 适合谁，不适合谁

**适合你，如果：**

- 有一批「旋律很熟、歌词没听懂」的英文歌
- 想练的是**真实语境里的英语**——俚语、连读、双关、情绪，而不是考试词汇表
- 背单词总是坚持不下来，需要一个「有上下文、有反馈」的方式
- 愿意每天花 10–20 分钟，而不是一次刷三小时

**不适合你，如果：**

- 你要的是应试题库、真题、语法系统课（这里没有）
- 你想要逐句对照翻译读完一首歌就走（这里的重点是「练会」，不是「看完」）
- 你不想配置任何东西、不想用 API Key（这是一个本地优先的自部署项目）

## 把它用成习惯：一周怎么练

工具本身不会让人坚持，节奏才会。下面这套节奏可以直接照搬：

| 时间 | 做什么 | 大概耗时 |
|---|---|---|
| 通勤 / 睡前 | 挑一首歌听一遍，遇到听不懂的句子**点一下问 AI**，看完就关 | 10 分钟 |
| 每天固定时段 | 同一首歌，收藏 **5–8 个**真正想用的词（不是所有生词） | 15 分钟 |
| 隔天 | 「词汇练习」盲打一轮 20 词，重点看错误率和 WPM | 10 分钟 |
| 周末 | 重打本周错词，再换一首新歌；顺手看看「数据分析」的弱点词 | 30 分钟 |

三个容易踩的坑：

1. **别贪多。** 一首歌收藏 5–8 个词就够了，收藏 40 个的结果通常是一个都不练。
2. **先问懂再收藏。** 没理解的词收进去，练的只是拼写，不是英语。
3. **允许自己跳过。** 队列前排老是同几个词时，练习页可以跳过，不必硬啃。

## 快速开始

### 环境要求

- Python **3.10+**
- Node.js **18+**（只在构建前端时需要）
- 一个 OpenAI 兼容的 LLM API Key（DeepSeek、OpenAI、通义、本地 vLLM 都行）

### 1. 安装后端

```bash
git clone https://github.com/ClaireLytt/music_agent.git
cd music_agent

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -e ".[web,llm,features]"
```

- `web`：FastAPI + uvicorn（Web 服务本体，必装）
- `llm`：调用大模型（AI 批注、问答、导读）
- `features`：单词发音（edge-tts）、韵脚分析等增强功能

> 想一次装全（含 embedding、MCP、旧版 Gradio 界面）可以用 `pip install -e ".[all]"`，但 `all` 里的 gradio 对本项目不是必需的。

### 2. 构建前端

前端是 React SPA，**必须先构建**，否则打开页面会是空白：

```bash
cd frontend
npm install
npm run build
cd ..
```

构建产物输出到 `frontend/dist/`，后端会自动托管它，不需要单独启动前端服务。

### 3. 配置 API Key

复制一份环境变量文件：

```bash
# Windows
copy .env.example .env
# macOS / Linux
cp .env.example .env
```

至少填这几项（以 DeepSeek 为例）：

```ini
LLM_PROVIDER=openai
API_KEY=sk-你的key
LLM_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-chat
```

也可以**跳过这一步**，启动后在界面「设置」页填写 Key、接口地址和模型名，保存即生效（Key 只存在本机 `data/user_settings.json`）。

### 4. 启动

```bash
python -m lyric_agent.cli serve-web
```

浏览器会自动打开 **http://127.0.0.1:8765**。

常用参数：

```bash
python -m lyric_agent.cli serve-web --port 8770    # 换端口（默认 8765）
python -m lyric_agent.cli serve-web --no-browser   # 不自动开浏览器（服务器/远程）
python -m lyric_agent.cli serve-web --sandbox      # 用 data/ 的临时副本跑，不污染真实曲库
```

> 远程服务器上部署时加 `--no-browser`，再用 SSH 端口转发访问：
> `ssh -L 8765:127.0.0.1:8765 user@server`

## 五分钟上手

以内置的《cardigan》（Taylor Swift）为例，走一遍完整闭环。

### ① 听：选歌、播放、看歌词

左侧曲库点《cardigan》，底部按播放。歌词会**逐句高亮**，当前句还有卡拉OK 式的渐变点亮（歌词带词级时间轴时逐字点亮，否则按句推进）。

不确定唱到哪？点任意一句歌词，播放头会**直接跳到那句**。

### ② 问懂：点一句听不懂的

点一句歌词（比如 `I knew you'd come back to me`），右侧解读坞会出现：

- **AI 助手** — 用中文讲这句的意思、语法和语气，还能接着追问
- **AI 批注** — 这句的修辞、情绪、用典，写成一小段点评
- **歌曲导读** — 整首歌的背景和主题，通读一遍再听

长任务都在后台跑：生成过程中你可以切歌、切页，回来结果还在。

### ③ 查词收藏：双击一个生词

在歌词里**双击** `vintage`，弹出词义卡：

- 音标 + 🔊 发音（点一下重播）
- 中文释义（来自本地词典，不花 AI 额度）
- **曲库里还有 N 处** — 展开看这个词在别的歌里怎么用，点一条直接跳过去听
- **✨ AI 语境解释** — 结合这句歌词讲这个词为什么这么用
- **⭐ 收藏单词** — 存进单词本，自动带上原句

拖选 2–16 个词可以查**词组**，同样能收藏。卡片可以拖动、最多同屏 4 张、Esc 全部关闭。

右侧「单词本」里能看到收藏的词，每个词都能写一句自己的笔记。

### ④ 练会：盲打

左侧导航进「**词汇练习**」：

1. 选练习范围：全部 / 歌词收藏 / 单词 / 词组，或自己导入的分组
2. 选每轮词数：10 / 20 / 50 / 全部
3. 开始盲打：看中文释义（或听发音）打出英文单词

- 打错一个字母，**整词从头再打**
- `Tab` 偷看答案，`Enter` 换下一个词
- 一轮结束看统计：一遍过比例、WPM、错词清单，可以「重打错词」
- 队列按错误次数排序：错得多的词在下一轮最前面
- 一个词被判定为「**掌握**」的条件是：盲打遮字、零偷看、零错误，连续 3 次

点「**数据分析**」看长期数据：近 30 天练习次数、每个词的练习/错误/错误率，以及最该补的弱点词。

### ⑤ 带走

「词汇练习」页底部：

- **导出 Anki** — 制表符分隔，导入 Anki 继续背
- **导出 JSON 词典** — qwerty-learner 格式，导入网页版练打字

## 功能详解

### 播放解读（`/`）

主界面，三栏布局，宽度都能拖：左曲库、中歌词、右解读坞。

**歌词区**

- LRC 时间轴逐句同步，当前句放大加粗，卡拉OK 式渐变点亮（有词级时间轴则逐字）
- 点句选中并跳播；选中状态不会随播放自动跑掉（方便你慢慢看）
- 双击查词、拖选查词组

**右侧解读坞**

| 模块 | 说明 |
|---|---|
| AI 助手 | 针对选中那句提问，支持多轮追问；问答按句保存，切回来还在 |
| AI 批注 | 单句的修辞 / 情绪 / 用典点评，逐句缓存 |
| 歌曲导读 | 整首的背景、主题、叙事线，长文缓存 |
| 听歌笔记 | 在当前播放时间点记笔记，点笔记跳回那个位置 |
| 歌词收藏夹 | 收藏这首歌的整句歌词，跟随歌曲保存 |
| 单词本 / 词组本 | 你收藏的全部单词与词组，可写笔记、可跳回原句 |
| 歌曲工具 | 上传音频、时间校准（毫秒）、替换歌词 |

**播放条**：上一首 / 播放暂停 / 下一首、进度拖动、音量、静音。

### 词汇练习（`/words`）

- **歌曲寻词**：盲打练习，题库来自你的单词本
- 分组：预设「全部 / 歌词收藏 / 单词 / 词组」，加上自己导入的分组
- 导入词表：CSV / TSV / TXT（第一列单词、第二列释义、第三列音标；Excel 请先另存为 CSV），可指定分组名
- 数据分析（`/words/analysis`）：练习曲线、逐词错误率、弱点词排行
- 导出：Anki（TSV）、JSON（qwerty-learner）

### 互动探索（`/explore`）

- **歌迷考据** — AI 把官方信息、歌词呼应、粉丝推测写成一篇可读的长文（有缓存）
- **歌词竞猜** — 给一句歌词，四选一猜它出自哪首歌；键盘 `1-4` 选择，`Enter` 提交/继续
- **歌名拼图** — 歌名被挖掉一个词（`____`），从四个选项里把它补回去
- 每轮结束有错题回顾

### 曲库管理（`/library`）

- 查看、搜索、排序（最新添加 / 歌名 / 歌手 / 专辑）
- 从内置热门歌曲目录**一键添加**（自动配歌词）
- **手动添加**任意歌曲：标题必填，歌手/专辑选填，歌词可上传 `.lrc` 或留空自动抓取
- 删除歌曲

### 设置（`/settings`）

- **API 设置**：Key、接口地址、模型名，保存即生效
- **语料库与 Embedding**：切换 embedding 模型并重建索引（中文歌为主的曲库建议换多语模型）
- **数据备份**：导出整个 `data/` 为 zip；从备份恢复（原数据自动留底）

## 添加自己的歌

### 方式一：界面添加（推荐）

1. 进「曲库管理」
2. 填标题（输入几个字会从热门歌曲里联想，选中后自动带出歌手/专辑）
3. 歌词可以上传 `.lrc`，留空则自动去 LRCLIB 找同步歌词
4. 保存

保存后回到播放页，在右侧「歌曲工具」里：

- **选择音频文件** — 上传本地 mp3/m4a，立即可播
- **歌词时间校准** — 填毫秒数微调（正数 = 歌词提前），保存即生效
- **更换歌词** — 上传新的 `.lrc` 直接替换

想配 MV？在右侧 MV 面板粘贴 BV 号或 B 站链接即可（留空保存 = 解绑），也可以先搜候选再选。

> 没有音频也能用：AI 问答、批注、查词、收藏、练习全部可用，只是不能播放。

### 方式二：直接放文件

在 `data/songs/` 下建一个目录，放这些文件：

```
data/songs/my_song/
├── metadata.json     # {"title": "...", "artist": "...", "album": "..."}
├── lyrics.lrc        # 带时间轴的歌词，必须
├── audio.mp3         # 可选，有就能播
├── cover.jpg         # 可选，封面
└── annotations.json  # 可选，AI 生成后自动写入
```

然后生成批注：

```bash
python -m lyric_agent.cli fetch-lrc data/songs/my_song     # 没歌词时先抓
python -m lyric_agent.cli generate data/songs/my_song      # 生成 AI 批注
```

## 命令行

所有命令都用 `python -m lyric_agent.cli <命令>` 调用（装好后也可直接用 `lyric-agent`）。

| 命令 | 作用 |
|---|---|
| `serve-web` | **启动 Web 应用**（本文档主入口） |
| `serve` | 启动旧版 Gradio 界面（已不推荐） |
| `generate <歌曲目录>` | 为单首歌生成 AI 批注，可断点续跑 |
| `generate-all` | 为曲库所有歌生成批注 |
| `fetch-lrc <歌曲目录>` | 从 LRCLIB 抓同步歌词 |
| `pipeline` | 全流程：抓歌词 → 批注 → 建语料库 → embedding → 时代聚合 |
| `search <关键词>` | 跨曲库搜歌词（`--semantic` 走语义检索） |
| `doctor` | 体检：重复歌曲、过期语料、缺失 embedding |
| `mcp` | 启动 MCP 服务器（stdio），接入 Claude Code / Desktop |

常用示例：

```bash
# 看曲库有没有问题
python -m lyric_agent.cli doctor

# 搜一句歌词出自哪首歌
python -m lyric_agent.cli search "vintage tee"

# 给新加的歌补批注
python -m lyric_agent.cli generate data/songs/my_song
```

## 数据、备份与隐私

**数据默认都在本机。** 没有云端账号，没有强制登录（`data/users.json` 不存在时无需登录），学习数据不上传。

会联网的只有这几处，都能接受再往下用：

| 请求 | 什么时候发生 | 能关吗 |
|---|---|---|
| 你配置的 LLM 接口 | 生成批注、问答、导读、AI 语境解释 | 不配 Key 就不会调用 |
| `dict.youdao.com` 发音 | 点词卡的 🔊 | 离线时静默失败 |
| `lrclib.net` 歌词 | 添加歌曲时自动抓歌词 | 手动上传 `.lrc` 就不会抓 |
| `itunes.apple.com` 试听 | 歌曲没有本地音频时兜底 | 上传本地音频即可 |
| `musicbrainz.org` / `coverartarchive.org` | 添加歌曲时补专辑封面 | 无封面时留空 |
| `bilibili.com` | 绑定 MV 后加载播放器 | 不绑 MV 就不用 |

```
data/
├── songs/<歌名>/          # 每首歌的歌词、批注、音频、封面
├── wordbook.json          # 单词本（收藏的词 + 原句 + 笔记）
├── favorites.json         # 歌词收藏夹
├── stats.json             # 练习记录与统计
├── cache/                 # AI 结果缓存（命中零调用）
├── corpus/                # 语料库与 embedding（互文检索用）
├── catalog/               # 内置可添加歌曲目录
├── evolution/             # 时代聚合数据
├── user_settings.json     # API Key、模型配置（不要提交到 git）
└── dict/                  # 本地词典
```

**备份**：设置页 →「导出全部数据 (zip)」，会把学习数据、AI 缓存、歌曲音频一起打包，**但会剥离 API Key**。换电脑时在新机器上「从备份恢复」即可，原数据自动留底为 `data.bak_时间戳`。

**缓存策略**：所有 AI 生成结果落盘永久缓存。同一句歌词的批注、同一首的导读、同一个词的语境解释，生成一次之后不再调用模型——省钱，也让你离线时仍能看到已生成的内容。

## 常见问题

**打开 127.0.0.1:8765 是空白页 / 404**
前端没构建。执行 `cd frontend && npm install && npm run build`，然后重启。

**`python -m lyric_agent.cli` 报 `No module named lyric_agent`**
包没装上或虚拟环境没激活。回到项目根目录，确认 `(.venv)` 前缀出现后执行 `pip install -e ".[web,llm,features]"`。

**能看歌词，但点了播放没声音**
这首歌没有音频文件。右侧「歌曲工具」上传音频，或绑定 B 站 MV 后在 MV 面板里看。

**AI 功能没反应 / 提示 `API_KEY is not set`**
到「设置」页填 Key 并保存，或检查 `.env` 是否在项目根目录、变量名是否拼对。

**AI 生成很慢 / 我切走了会不会丢**
不会。所有长任务都在后台跑并落盘，切歌、切页、刷新都不影响，回来结果还在。

**曲库里怎么只有英文歌**

## 技术栈与目录

| 层 | 技术 |
|---|---|
| 前端 | React 18 + TypeScript + Vite，Tailwind CSS，TanStack Query，zustand，Recharts |
| 后端 | FastAPI + uvicorn（薄 API 层，不搬业务逻辑） |
| 数据/引擎 | 自研：`songdata`、`annotator`、`dictionary`、`intertextuality`、`quiz` |
| LLM | 任意 OpenAI 兼容接口（DeepSeek 默认），Anthropic 亦可 |

```
src/lyric_agent/
├── cli.py            # 命令行入口（serve-web 在这里）
├── api.py            # FastAPI 路由层
├── songdata.py       # 歌曲数据读写
├── annotator/        # AI 批注生成引擎
├── dictionary.py     # 词典、单词本
├── review.py         # 盲打练习、导出
├── occurrences.py    # 单词全库检索
├── config.py         # 环境变量与用户设置
└── mcp_server.py     # MCP 接口

frontend/src/
├── App.tsx           # 路由与播放页布局
├── components/       # 歌词、解读坞、查词卡、练习
└── pages/            # 词汇练习、互动探索、曲库管理、设置

data/                 # 曲库与全部学习数据（本地）
docs/                 # 架构、设计、调研文档
```
